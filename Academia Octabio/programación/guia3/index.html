Nuevo concepto

Un clon permite que un mismo objeto aparezca varias veces

Un clon es una copia idéntica de un objeto original que se crea mientras el programa está funcionando. Así podemos hacer que un mismo personaje o elemento aparezca muchas veces sin crearlo manualmente uno por uno.

Objeto original

Es el objeto principal del que se crean las copias.

Clon

Es una copia idéntica del objeto original creada durante la ejecución.

Muchos clones

Podemos crear varias copias del mismo objeto automáticamente.

Acciones por separado

Los clones, una vez creados, pueden realizar acciones por separado.

Scratch

Los bloques de un clon

En Scratch, para trabajar con clones usas 3 bloques principales.

Crear clon de mí mismo

Crea una copia del objeto actual.

Al comenzar como clon

Cada vez que se crea un clon del objeto, este bloque ejecuta las acciones que programes para el comportamiento del clon.

Eliminar este clon

Borra el clon cuando ya no se necesita.

!

Los clones nacen y mueren mientras el programa se ejecuta; el objeto original siempre permanece.

Atrapa la cosecha

¡La cosecha está lista, pero hay un problema! Las manzanas no permanecerán frescas para siempre.

Tu misión

Es rescatar la mayor cantidad posible de manzanas antes de que sea demasiado tarde. Cada manzana que salves aumentará tu contador de Manzanas recolectadas.

Primera parte: preparamos el escenario y los personajes del juego.
Segunda parte: programamos el juego y trataremos de recolectar todas las manzanas posibles.

En este reto crearás una nueva programación usando el cambio de disfraz que preparaste anteriormente. Tendrás que recoger las manzanas lo más rápido posible antes de que pase el tiempo y cambien a su disfraz de manzana podrida. Si no las atrapas a tiempo, ya no podrás recolectarlas.
